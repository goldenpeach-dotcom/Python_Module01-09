＜トップレベルの依存関係＞
tournamant.py
    ├── ex0.factories (FlameFactory, AquaFactory)
    ├── ex1.factories (HealingCreatureFactory, TransformCreatureFactory)
    └── ex2.strategies (Normal, Aggressive, Defensive)



＜Factory->Creatureの関連図＞
ex0.factories/
    ├── CreatureFactory
    │     └── create_base() → Creature（抽象）
    ├── FlameFactory
    │     └── create_base() → Flameling
    └── AquaFactory
          └── create_base() → Aquabub

ex1.factories/
    ├── HealingCreatureFactory
    │     └── create_base() → HealCreature
    └── TransformCreatureFactory
          └── create_base() → TransformCreature

Factory は「どの Creature を作るか」を決めるだけ。
tournamant.py は Factory を使って クリーチャーの実体を生成する。

＜Strategy -> act()の関係図＞
ex2.strategies/
    ├── BattleStrategy (抽象)
    │
    ├── NormalStrategy
    │     └── act(creature) → メッセージ一覧
    ├── AggressiveStrategy
    │     └── act(creature) → メッセージ一覧
    ├── DefensiveStrategy
    │     └── act(creature) → メッセージ一覧
    └── InvalidStrategyError
Strategy は「クリーチャーがどう戦うか」を決める。
tournamant.py は Strategy を使って 戦闘ログを生成する。

＜tournamentが使う組み合わせの図＞
FactoryとStrategyのペアを定義
Opponent = tuple[CreatureFactory, BattleStrategy]
Opponent
   ┌──────────────┬──────────────────┐
   │ Factory       │ Strategy         │
   ├──────────────┼──────────────────┤
   │ FlameFactory  │ NormalStrategy   │
   │ HealingFactory│ DefensiveStrategy│
   │ AquaFactory   │ NormalStrategy   │
   │ TransformFact │ AggressiveStrategy│
   └──────────────┴──────────────────┘

＜トーナメントの処理フロー＞
test_tournament(opponents)
    │
    ├─ opponents = [(Factory, Strategy), ...]
    │
    ├─ fighters = []
    │    for each (factory, strategy):
    │        creature = factory.create_base()
    │        fighters.append( (creature, strategy) )
    │
    ├─ 全組み合わせでバトル開始
    │    for i in fighters:
    │      for j in fighters (i < j):
    │
    │        first_creature,  first_strategy
    │        second_creature, second_strategy
    │
    │        first_strategy.act(first_creature)
    │        second_strategy.act(second_creature)
    │
    │        → メッセージを表示
    │
    └─ InvalidStrategyError が出たらトーナメント中止
